# SYNERGY 2026 · United University

Website for SYNERGY 2026, the annual fest of United University, Prayagraj (5–6 December 2026, with Sachin-Jigar live at Star Night on 6 December).

Live site: https://ashutosh26-uu.github.io/senergy2026/

## What's inside

- A real-time 3D concert stage (Three.js) that the camera flies through as you scroll
- Countdown to the fest, SYNERGY 2026 details and the Star Night
- SYNERGY 2025 archive with event flyers by day, the recap video, and past editions
- Campus gallery, venue map and contact details

It is a static site with no build step. Open `index.html` through any local server, for example:

```bash
python -m http.server 5173
```

Fest dates and the countdown are set in `window.FEST` at the top of `js/main.js`.
